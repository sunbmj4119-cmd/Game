# Moon Sweepers 분석과 제설각 적용안 (2026-11)

> 요청: "Moonsweepers라는 게임 참고해서 분석해봐. 난 이런 식의 게임을 원해."
> 상점 페이지와 기사 본문은 이 환경에서 열리지 않아 검색 결과 요약과 공략 사이트를 근거로 했다. 공략 사이트 숫자는 패치마다 다를 수 있다. 시점(1인칭/3인칭)은 확인하지 못했다.

## 1. 어떤 게임인가
- DragDrop Games(핀란드 소규모 스튜디오), 2026-10-23 출시, 8.99달러(출시 15% 할인), 최대 16인 온라인 협동, 혼자도 가능
- 설정: 달 청소 회사 직원이 **칫솔 하나로 달 전체를 청소**한다
- 출시 1주 만에 누적 60만 명, 스팀 동시접속 최고 약 7만~8.3만 (추적 사이트마다 다름)

## 2. 어떻게 진행되나
1. **쓸어 담기**: 칫솔은 먼지 0.5kg만 담긴다
2. **나르고 팔기**: 통이 차면 정거장(데포)까지 가서 판다. 1kg에 약 1달러
3. **도구·차량**: 가정용 빗자루 $25 → 건설 도구 $50 → 넓은 빗자루 $75 → 차고 $200 → 밀대 청소기 $300(첫 차량) → 탑승형 청소기 $1,000 → … → 3,000kg 메가 진공 로버. 차량마다 적재량·폭·속도, 모터·조명 업그레이드
4. **우주복**: 걷기 +7/14/21%, 제트팩, 중력 부츠(저중력 → 지구 중력)
5. **공장**: 건설 도구로 포장기 → 컨베이어 → 압력실(먼지 5kg/12초 → 달모래) → 돌 압착기(달돌, 가장 비쌈), 캡슐 캐처
6. **자동화**: 로봇 청소기(도크 주변 범위를 알아서 청소), J.O.O.N.A.S.($20,000, 더러운 구역을 스스로 돌며 치우고 꽉 차면 캡슐을 쏴 보냄), 자동 판매
7. **협동**: 구역을 나누거나 같이 치운다. 돈 공유(1.0.3 패치부터 업그레이드도 공유). 전투 없음

## 3. 왜 떴나
- 한 줄로 설명되는 황당한 전제(달을 칫솔로) — 캡처·방송각
- 친구 여럿이 하는 혼돈(Lethal Company·Peak·R.E.P.O.로 이어진 흐름), 싼 가격
- 세 단계 손맛: **손(칫솔) → 차(로버) → 공장·로봇**. PowerWash의 즉각적 손맛 + 증분형 성장 + 팩토리 자동화
- **치운 곳이 남는다**: 지도에 "여기까지 우리가 치웠다"가 쌓인다

## 4. 비판
- 초반에 금방 진척 벽, 자동화가 충분히 빠르지 않다
- 2시간쯤이면 거의 다 연다(콘텐츠 부족)
- 출시 초 성능·멀티 버그, 지은 건물을 못 옮긴다, 16명 조율 도구 부족

## 6. 제설각 적용안
1. **퍼 담고 → 나르고 → 버리기**: 도구마다 적재량. 꽉 차면 '눈 집하장'까지 가서 부어야 초코파이. 마대자루 → 외발수레 → 리어카 → 소형 제설기 → 트랙터 → 덤프트럭
2. **타이머 없는 부대**: 치운 곳은 깨끗하게 남는다. 가끔 폭설이 와서 다시 덮고, 구역을 다 치우면 행보관 검열(보상)
3. **군대식 공장 = 인간 컨베이어**: 후임들을 줄 세워 양동이 릴레이, 눈 압축기(눈벽돌 ×3), 눈조각 작업장(사단장님 환영 눈사람·이글루 ×10)
4. **차량은 직접 운전**: 폭·적재량·속도 업그레이드
5. **자동 인력**: 후임은 맡은 구역만 도는 로봇 청소기, 말년 병장은 J.O.O.N.A.S.처럼 알아서 돌아다니지만 존다
6. **방해꾼**: 유지하되 수위 조절 (예: 고라니가 집하장 눈더미를 무너뜨림)
7. **협동**: 웹에서 실시간 16인은 서버가 필요해 어렵다 → AI 동기들로 대신, 나중에 같은 부대 랭킹
8. **콘텐츠 벽 피하기**: 구역 8곳 + 가공 단계 + 전역(다시 시작) + 날씨
