# 전역각 🪖

> **전역날까지 버텨라!** 띨빵한 군인들과 함께하는 한국 군대 생존 카드 게임 (휴대폰 세로 화면용 웹 게임)

카드를 좌우로 넘겨 선택하고 **체력 · 멘탈 · 간부 신뢰 · 전우애** 네 가지를 지켜내세요.
하나라도 **0이 되거나 100이 되면 전역 실패**입니다. 너무 열심히 하면 중대장이 장기복무 서류를 내밉니다.

- 육군 18개월 실제 달력(입대일 → 전역일), 진급(이병 → 병장), 매월 10일 월급, 장병내일준비적금
- 훈련소 5주 → 자대 배치 → 짬타이거, 곰신, 후임, 왕고, 행보관, 사단장 방문까지 이벤트 카드 380여 장 · 장면 830여 개
- 돌발 미니게임 6종: 비상 소집 · 제설 작업 · 불침번 · 사격 · 탄피 찾기 · 선임 이름 외우기
- PX 아이템, 휴가(포상휴가 · 말년휴가 후 그대로 전역), 엔딩 19종 도감
- 외부 이미지 없이 코드로 그린 띨빵한 캐릭터들 (큰 머리, 짝짝이 눈, 콧물 풍선)

## ❄️ 외전: 제설각 (`snow.html`)

> **눈은 하늘에서 내리는 쓰레기다.** 싸리비 하나로 시작해서 넉가래, 제설차, 헬기까지. 후임·동기·말년 병장·예비군 아저씨를 초코파이로 부려 먹으며 부대 전체를 치운다.

- **퍼 담고 → 나르고 → 붓기** (Moon Sweepers식): 짐이 가득 차면 눈 집하장까지 가서 부어야 초코파이. 치운 곳은 그대로 남고 저장된다
- **공장**: 양동이 릴레이(인간 컨베이어), 눈 압축기, 사단장님 환영 눈사람 작업장
- 한 손 조작: 화면을 누른 채 끌면 걷고(조이스틱), 톡 하면 그쪽으로 간다. 도구는 알아서 민다
- 하루 타이머 없이 계속 이어진다. 구역을 거의 다 치우면 **행보관 검열 통과**, 조각마다 **띵!**
- **도구 9단계**: 싸리비 → 넉가래 → 대형 넉가래 → 쌍넉가래 → 손수레 제설기 → 염화칼슘 살포기 → 트랙터 → 군용 제설차 → 제설 헬기
- **인력 7종**: 후임, 동기, 취사병, 말년 병장(40%는 잔다, 행보관이 깨운다), 행정병, 예비군 아저씨, 제설차
- **구역 6곳**: 생활관 앞 길 → 마당 → 연병장 → 진입로 → 위병소 앞 → 헬기장. 치우면 바닥의 '충성', '서행', 'H'가 드러난다
- 날씨(잔설·눈·함박눈·폭설 경보), 7일마다 대대장 순시, 다 치우면 조기 퇴근 보너스
- 진급(이병 → 병장) 때마다 새 인력, **전역 신고**로 처음부터 다시 + 전역 메달(모든 보상 +10%씩)
- 앱을 꺼 둔 동안에도 인력이 일한다(최대 8시간)
- **3D 3인칭**: 플레이어 뒤 낮은 카메라, 하늘·설산·해, 실시간 그림자. 군인은 3D 몸에 전역각 얼굴을 입힌 머리. 눈을 파면 바닥의 '충성'·'족구장'·'H'가 드러난다 (`시점` 버튼으로 위에서 보기)
- **열받는 것들**: 고라니(꾸에에엑! 부딪히면 부상·초코파이 떨어뜨림), 선임 눈덩이, 진흙눈 뿌리는 간부 차량, 지붕 눈 낙하
- **띵!**: 구역 조각을 다 치우면 띵 + 보너스, '남은 눈' 버튼으로 놓친 곳 하이라이트 (PowerWash Simulator에서 배움)
- 설계와 숫자: [`docs/SNOW.md`](docs/SNOW.md)

## 바로 플레이

### 컴퓨터에서
```bash
# 저장소 폴더에서
python3 -m http.server 8000
# 브라우저로 http://localhost:8000 접속 (개발자 도구 → 휴대폰 화면 모드 추천)
```
`index.html`을 더블클릭해서 열어도 동작합니다(오프라인 캐시만 빠짐).

### 휴대폰에서
1. **GitHub Pages로 올리기** — 저장소 *Settings → Pages → Branch* 에서 이 브랜치와 `/ (root)`를 선택하면 `https://<아이디>.github.io/<저장소>/` 주소가 생깁니다.
2. 휴대폰 브라우저로 접속 → **홈 화면에 추가**(iOS: 공유 → 홈 화면에 추가 / 안드로이드: 메뉴 → 앱 설치).
   앱처럼 전체 화면으로 열리고, 한 번 접속하면 오프라인에서도 플레이됩니다(PWA).
3. 파일 하나로 보내고 싶다면 `node tools/build.js` → `dist/jeonyeok.html` 하나만 휴대폰으로 보내서 열면 됩니다.

### 앱스토어 앱으로 만들려면 (선택)
웹 기술로 만들었기 때문에 [Capacitor](https://capacitorjs.com)로 감싸면 안드로이드/iOS 앱이 됩니다.
```bash
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init 전역각 kr.example.jeonyeok --web-dir .
npx cap add android && npx cap open android   # Android Studio에서 빌드
```

## 조작
| 동작 | 방법 |
|---|---|
| 선택 (훈련소·사건 카드) | 카드를 왼쪽/오른쪽으로 끌기, 또는 아래 버튼을 **두 번** 탭 |
| 자대에서 걷기 | 지도를 누른 채 끌기(조이스틱) · 물건·사람을 톡 · 방향키/WASD, 행동은 아래 패널(또는 E) |
| 영향 미리보기 | 카드를 살짝 끌면 바뀔 스탯 위에 점이 뜸 (큰 점 = 크게 변함, 방향은 비밀) |
| 결과 넘기기 | 결과 쪽지 아무 데나 탭 |
| 가방 / PX / 동료 / 휴가 / 메뉴 | 하단 도크 (쓸 수 있을 때만 버튼이 나타남. PX는 열리면 '띠링') |
| 내 정보 | 위쪽 이름을 탭 (날짜·부대·이번 주 상황), 이름 밑 아이콘을 탭하면 설명 |
| 돌발 상황 | 빨간 경보가 먼저 뜬다 → 탭하면 시작 → 빨간 막대(남은 초)가 끝나기 전에 선택. 놓치면 어떻게 되는지 아래에 표시 |
| 말 걸기 | 카드 속 인물을 톡 |
| ⭐ 특수 대답 | 카드를 위로 밀기, 또는 금색 버튼 두 번 |
| 되돌리기 | 결과 쪽지의 ⌚ 버튼 (국방부 시계 강화 필요) |
| 키보드 | ← → 로 선택(두 번 누르면 결정), Enter로 계속 |

### 카드 추가하기
자세한 형식·균형·길이 규칙은 [`docs/CONTENT.md`](docs/CONTENT.md). 새 파일을 만들었다면 `index.html`의 `<script>` 목록과 `sw.js`에 추가하고 `node tools/lint-cards.js 새파일`로 검사합니다.
간단히는 `js/data/cards.js`의 `CARDS` 배열에 하나 넣으면 됩니다.
```js
{
  id: 'my_card', who: 'haeng', bg: 'field', req: { season: 'winter', rank: [2, 4] },
  text: '행보관: "오늘은 연병장에 눈사람 금지다."',
  l: o('"네!"', { tr: 6, mt: -4 }, '행보관이 흡족해했다.'),
  r: o('몰래 만든다', { mt: 8, tr: -8 }, '눈사람이 행보관을 닮았다.')
}
```
수치는 `core.js`의 `BALANCE` 표로 한 번 보정되니, 추가한 뒤 `tools/simulate.js`로 성공률을 확인하세요.
