# 제설각 v20: 보고·보급은 버튼으로 · 상자는 생활관에서도 · 운전은 짬 순서 · 호봉과 군생활 % (2026-11)

> 요청: "보급 상자 오픈하는 게 게임 안에서만 있는 거랑, 작업 완료 보고랑 장비를 업그레이드하는 방법이 너무 비효율적이야. 작업하면서는 업그레이드할 수 있는 화면을 따로 열게 해 주거나, 완료 보고는 좀 더 좋은 방법으로 하게 해 줘. 그리고 제설차는 벌써 탈 수 있는 게 맞아? 일병 짬찌가 할 수 있는 건지 의문이야. 호봉제도 좀 넣어서 군생활 퍼센트로 표시해 주면 좋을 것 같아."

## 1. 작업 완료 보고: 초록 버튼

| | 전 | v20 |
|---|---|---|
| 보고 | 보고 원(행보관 앞)까지 걸어가서 0.6초 서 있기 | 지시서를 끝내면 **왼쪽 아래 지시서 카드 위에 초록 "작업 완료 보고 ▶" 버튼**이 뜬다 (띵 소리·진동). 누르면 바로 검열 결과 |
| 안내 | "보고 원 위에 서 있기" | "왼쪽 아래 초록 버튼 · 일찍 할수록 수당". 100%면 "완벽! 누르면 바로 보고" |

- 보고 원도 그대로 둔다 (걸어가도 된다)
- 오른쪽 아래는 행동·눈덩이 버튼이라 일부러 왼쪽에 뒀다. 지시서 카드가 없는 날(구역 하나)에도 같은 자리

## 2. 작전 중 보급: 위 버튼 줄에 "보급"

- 작전 화면 위 버튼 줄(일시 정지 · 상자 · 시점 · 남은 눈) 옆에 **보급** 버튼. 지금 살 수 있는 것 수가 빨간 숫자로 뜬다
- 누르면 작전이 멈추고 보급 화면(장비 · 인원 · 강화)이 열린다. 아래 버튼이 **"작전으로 돌아가기"** — 누르면 생활관을 거치지 않고 바로 작전이 이어진다
- 산 장비·개인 장비는 돌아가자마자 적용된다. 인원은 원래대로 다음 날 아침 전입
- 행보관 앞 보급 원도 그대로 (지나가다 서 있으면 다음 장비)
- v10에서 "작전 중엔 눈과 사람에만 집중"하려고 숨겼던 버튼이다. 걸어가는 게 번거롭다는 얘기라 다시 열었다

## 3. 보급 상자를 생활관에서도

- 전엔 ★★★·아침 점호·훈장·패스로 받은 상자를 **작전 화면 위 상자 버튼으로만** 열 수 있었다
- 이제 생활관 **장구 → 보급 상자 탭** 맨 위에 "받은 보급 상자 N개 (전설 · 희귀 · 일반 몇 개)" — **하나 열기**(상자가 흔들리다 열리는 연출) / **모두 열기**(한 장으로 정리: 나온 장구를 등급순으로, 초코파이·상점·부품·분실물 합계, 합성할 게 생겼으면 알림)
- 받은 상자가 있으면 장구 버튼 배지에 숫자가 더해지고, 장구를 누르면 보급 상자 탭부터 열린다

## 4. 운전은 짬 순서

| 탈것 | 전 | v20 |
|---|---|---|
| 리어카 (미는 것) | 일병 | 일병 |
| 제설 사륜바이크 | 취사장 앞을 맡으면 (일병) | **상병** |
| 트랙터 | 상병 | **병장** |
| (장비) 보행식 제설기 · 살포기 / 트랙터 제설기 · 군용 제설차 | 상병 / 병장 | 그대로 |
| (분대원) 제설차 운전병 | 병장 | 그대로 |

- 아직 못 모는 탈것 옆에 서면 혼잣말: "(사륜바이크… 키는 상병부터 준다고 했다)", "(일단 넉가래나 잡자. 트랙터는 병장 돼서)"
- 일병 때 '제설차'처럼 보이던 건 사륜바이크(앞에 삽날)였다. v19에서 공병대 제설차 지원도 상병·폭설 날로 미뤘다

## 5. 호봉과 군생활 %

★(근무평정) 진행을 **18개월 복무**로 본다. 한 달 = 1호봉.

| 계급 | 기간 | 호봉 | 군생활 % (시작) | ★ 구간 |
|---|---|---|---|---|
| 이병 | 2개월 | 1~2호봉 | 0% | 0~6 |
| 일병 | 6개월 | 1~6호봉 | 11% | 6~24 |
| 상병 | 6개월 | 1~6호봉 | 44% | 24~60 |
| 병장 | 4개월 | 1~4호봉 | 77% | 60~150 |
| 전역 | | | 100% | 150 |

- 생활관 내 카드: "일병 김 / 삽질 장인 · 3호봉 · 군생활 **28%**" (특기가 없으면 "· 전역 13개월 전"), ★ 막대 아래에 군생활 막대(초록, 가늘게)
- **월급날**: 작전이 끝나고 호봉이 오르면 결과 화면에 "월급날! 일병 3호봉 · +3,000". 이병 400 · 일병 3,000 · 상병 30,000 · 병장 120,000 (전역 메달 배율 적용). 가상 플레이어(효율 0.5)로 돌리면 전체 수입의 13% 정도, 전역까지 걸리는 시간은 그대로(작전 시간만 75~78분)
- 호봉이 안 올라도 "군생활 27% → 29%"
- 진급 심사에 붙지 못하면 마지막 호봉에서 멈춘다 (진급 누락). 진급한 날은 월급 대신 진급 보상, 새 계급 1호봉부터
