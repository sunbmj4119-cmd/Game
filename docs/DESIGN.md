# 전역각 — 게임 기획서

> **한 줄 소개**: 띨빵한 군인들 사이에서 18개월을 버텨 전역하는 모바일 생존 카드 게임.
> 카드를 좌우로 넘겨 선택하고, 체력·멘탈·간부 신뢰·전우애 네 가지가 0이나 100에 닿지 않게 균형을 잡는다.

---

## 1. 컨셉

| 항목 | 내용 |
|---|---|
| 장르 | 스와이프 선택형 생존 시뮬레이션 (Reigns 계열) + 돌발 미니게임 |
| 플랫폼 | 휴대폰 세로 화면 웹앱(PWA). 설치·오프라인 지원, 앱스토어 패키징 가능 |
| 목표 | 입대일부터 전역일(입대일 + 18개월 − 1일)까지 버티기 |
| 톤 | 코미디 7 : 현실 고증 3. 웃기지만 "우리 부대에도 있었다" 싶은 이야기 |
| 한 판 | 정상 복무 약 120장(30분 내외), 속성 복무 약 45장(10분 내외) |

**핵심 재미**
1. *균형의 딜레마* — 너무 못해도, 너무 잘해도 망한다. 간부 신뢰가 100이면 말뚝(장기복무), 전우애가 100이면 단체 일탈 주동자.
2. *펀치라인* — 선택 직후 결과 쪽지에 한 줄 개그. 군필자는 공감하고 미필자는 웃는다.
3. *돌발 상황* — 새벽 5분대기조, 탄피 분실, 멧돼지 출몰, 사단장 방문 같은 이벤트가 미니게임으로 튀어나온다.
4. *수집* — 19개 엔딩(전역 9 · 실패 10), 연계 스토리(짬타이거, 곰신, 후임, 왕고).

## 2. 레퍼런스 분석

### Reigns (스와이프 왕국 경영)
- **가져온 것**: 좌우 스와이프 = 이지선다, 네 개의 스탯, **양 끝이 모두 죽음**인 규칙. 극단을 피하게 만들어 "무조건 좋은 선택"이 없다.
- **가져온 것**: 카드를 끌면 영향을 받는 스탯 위에 점이 뜨고 **크기만 보여주고 방향은 숨긴다**. 텍스트를 읽고 추론하게 만드는 장치.
- **보완한 것**: Reigns는 결과 피드백이 없어 맥락이 약하다는 평이 있다 → 선택 후 *결과 쪽지*에 한 줄 개그 + 수치 변화를 보여준다.
- **보완한 것**: 순수 랜덤 드로우로 "좋은 선택이 없는" 상황이 생긴다는 비판 → 스탯이 위험 구간이면 *구조 카드*(상담관, 의무병, 중대장 면담 등)가 높은 확률로 나온다.

### This War of Mine / Don't Starve (생존 관리)
- **가져온 것**: 시간이 흐르면 몸과 마음이 소모된다. 카드 전체의 평균 효과를 체력·멘탈은 살짝 마이너스로 맞춰 두고, **PX 아이템과 휴가**라는 자원으로 회복하게 했다.
- **가져온 것**: 계절. 여름엔 유격·장마·모기, 겨울엔 제설·혹한기, 가을엔 낙엽, 봄엔 진지공사가 나온다.
- **가져온 것**: 감정적인 피드백. 숫자보다 사건(여자친구의 편지, 후임의 눈물, 엄마의 소포)이 기억에 남게 한다.

### BitLife (텍스트 인생 시뮬레이션)
- **가져온 것**: 짧은 텍스트 이벤트, 연계 스토리, 친구에게 자랑하고 싶은 이상한 엔딩(말뚝, 생활관 부처, 코인 부자).

### 국내 군대 게임 (앱스토어·스토브)
- *전역은 오는가* — 실제 군생활 기반 추리 어드벤처. *군인 생활 시뮬레이터*, *가상 육군 남자 시뮬레이터* — 진급·육성 중심.
- **차별점**: 대부분 "장군까지 승진"이나 "추리"가 중심. 전역 자체를 생존 목표로 놓고, 한국 병사 일상의 디테일을 개그로 푼 게임은 드물다.

### 드라마 '신병'(장삐쭈) · '푸른거탑'
- 연출자 인터뷰: 군대는 위계가 엄격하고 극단적인 상황이 많아 **코미디에 최적의 공간**, '신병'은 코미디 70 : 부조리 30.
- 인기 요인: 완벽에 가까운 고증, *어디에나 한 명쯤 있을 법한* 캐릭터.
- '푸른거탑'에 대한 비판: 과장이 지나치면 몰입이 깨진다 → **현실에 있는 일을 한 번만 비틀기**를 원칙으로 했다.
- 가혹행위는 웃음 소재로 쓰지 않는다. 요즘 병영 문화(마음의 편지, 상담관, 휴대폰 사용, 심부름 금지)를 반영했다.

## 4. 시스템

### 4-1. 스탯 (0 또는 100이면 전역 실패)
| 스탯 | 0이 되면 | 100이 되면 |
|---|---|---|
| 체력 | 국군병원 VIP | 특급전사의 함정 (부사관 지원) |
| 멘탈 | 멘탈 가루 (상담) | 생활관 부처 (해탈) |
| 간부 신뢰 | 군기교육대 입소 | 말뚝 엔딩 (장기복무) |
| 전우애 | 생활관 투명인간 | 생활관 대통령 (단체 일탈 주동) |

### 4-2. 카드 (총 160여 장)
- 훈련소 8장(고정 순서) → 자대 도착 3장(고정) → 일반 카드 무작위.
- 조건: 계급, 계절, 보직, 플래그, 변수, 스탯 구간, 남은 일수.
- 결과 종류: 고정 효과, 확률 결과(`roll`), 조건 결과(`cases`), 미니게임, 엔딩, 휴가 통제, 아이템·돈·휴가 지급.
- **연계 스토리**: 짬타이거 5단계(→ 입양 엔딩), 여자친구(호감도 변수 → 꽃신/이별), 후임 오순둥, 왕고 김말년 전역, 분대장 임명, 사단장 방문 → 온수 건의, 자격증, 코인.
- **보직 전용**: 소총수·취사병·행정병·운전병·의무병마다 전용 카드와 패시브.
- **위기 카드**: 스탯이 위험 구간이면 가중치 4~6으로 등장해 숨통을 틔워 준다.

### 4-3. 시간
- 카드 한 장 = 3~6일(속성 복무는 ×3). 매일 넘어갈 때 월급(10일), 진급(1일), 계절 변화를 처리.

### 4-4. 자원
- **PX**: 아이템 10종. 각 아이템은 스탯 두 개를 반대로 움직여서 "올리기/내리기" 도구가 된다(예: 귀마개 = 체력↑ 전우애↓). 아이템 효과는 5~95 안에서만 움직여 아이템으로 죽지 않는다. 한 번 다녀오면 4일(속성 12일) 뒤 재방문.
- **휴가**: 멘탈·체력 회복, 날짜 스킵. 복귀 후 20일 쿨다운, 진돗개·훈련으로 통제될 수 있다. 복귀 카드 중 "한 시간만 더…"는 군생활 중 한 번만 등장.

### 4-5. 미니게임 6종
| 미니게임 | 조작 | 결과 |
|---|---|---|
| 비상 소집 | 장비 6개를 순서대로 탭 (오답 −1초) | 3.5초 이상 남기면 대성공 |
| 제설 작업 | 화면 문지르기, 눈은 계속 쌓임 | 80% 이상 치우면 대성공 |
| 불침번 | 연타로 눈꺼풀 들기, 당직사관 순찰 3회 | 순찰 때 졸면 실패 |
| 사격 | 튀어나오는 표적 탭, 체력·멘탈 낮으면 조준 흔들림 | 9/10 특등사수 → 포상휴가, 30% 확률로 탄피 분실 이벤트 |
| 탄피 찾기 | 풀숲에서 반짝이는 탄피 3개 찾기 | 5초 이상 남기면 대성공 |
| 선임 이름 외우기 | 얼굴·이름 5초 암기 후 4문제 | 4/4 대성공 |

### 4-6. 엔딩 19종
전역 9종(민간인 등극, 모범 전역, 말출 전역, 짬타이거 입양, 꽃신, 깁스, 특급전사·특등사수, 코인 부자, 눈물의 전역식) + 실패 10종(스탯 8 + 탈영 + 휴가 미복귀). 전역할 때 조건을 여러 개 만족하면 모두 도감에 기록된다.

## 5. 밸런스

`node tools/simulate.js 2000 1` 로 확인한다.

| 플레이 방식 | 정상 복무 성공률 | 속성 복무 성공률 |
|---|---|---|
| 무작위로 넘기기 | 약 1% | 약 26% |
| 정보를 다 아는 최적 플레이 | 약 90% | 약 98% |

- 무작위 플레이의 실패 엔딩이 네 스탯에 고르게 퍼지도록 `core.js`의 `BALANCE` 표로 카드 수치를 보정했다.
- 실제 플레이어는 방향을 텍스트로 추론하므로 두 수치 사이(대략 40~70%)에 위치할 것으로 예상.
- v2(돌발 상황·주간 상황 추가) 기준 정상 복무 한 판에 돌발 상황 평균 8회, 속성 복무 약 3회.

## 6. 아트 방향

- 이미지 파일 없이 **SVG를 코드로 생성**. 큰 머리, 짝짝이 눈, 일자 눈썹, 뻐드렁니, 콧물 풍선, 침, 땀방울.
- 디지털 무늬(화강암 패턴) 전투복, 말년 병장의 깔깔이, 행보관의 삽, 조교 모자, 사단장의 별 두 개.
- 배경 12종 + 계절 오버레이(눈, 낙엽, 꽃잎). 눈 깜빡임·숨쉬기·콧물 애니메이션.
- UI 세계관: 카키 종이, 국방색 명찰 띠, 놋쇠 계급장, 빨간 직인. 시작 화면은 *입영 통지서*, 엔딩은 *전역증* / *전역 보류 통지서*.

## 7. 반복 플레이 요소 (v2)

한 판이 끝나도 다시 하고 싶게 만드는 장치들. 로그라이트(매판 다른 조건) + 메타 성장(판을 넘어 쌓이는 보상) + 경쟁(랭킹) 구조.

### 7-1. 매판 달라지는 조건
| 요소 | 내용 |
|---|---|
| 자대 5종 (무작위 배치) | 강원도 GOP(휴가↑·겨울 혹독) · 수도권 기계화(PX 할인·사단장 자주 방문) · 해안 경계(멘탈 회복↑·갈매기) · 신병교육대 조교(훈련병 이벤트) · 특공 연대(체력 극단·천리행군). 부대마다 전용 카드 4~5장 |
| 성격 카드 13종 | 입대할 때 3장 중 1장 선택(1회 다시 뽑기). 먹보·잠꾸러기·인싸·원칙주의자·유리멘탈(보상 1.3배)·강철멘탈·운동광·금수저·행운아·눈치백단·고양이 집사·연애 고수·덜렁이(돌발 2배) |
| 주간 상황 12종 | 매달 1일 40% 확률로 시작해 카드 3~5장 지속. 독감 유행, 폭염·한파, 짬밥 개선, 행보관 특별 점검, PX 반값 세일, 훈련 주간(휴가 통제) 등 |
| 날짜 이벤트 | 설날·추석·크리스마스·새해·국군의 날·하계 휴양소·호국보훈의 달 |

### 7-2. 돌발 상황 18종 (제한 시간)
카드마다 약 8% 확률(부대·성격에 따라 증감)로 사이렌과 함께 등장. 4~6초 안에 고르지 않으면 *얼어붙었다* 결과가 나온다.
사단장 불시 방문, 화재 경보, 침상 밑 뱀, 당직사관 불시 점검, 말벌집, 예능 촬영팀, 진흙에 빠진 보급 트럭, 지진, 반짝이는 무언가(다이아), 산불, 아이돌 출신 신병, 단체 배탈, 멧돼지 난입, 중대장 결혼식 축가, 진돗개 둘, 기습 폭우, 로또 당첨 선임, 불시 화생방.

### 9-3. 사람들이 계속할까 — 솔직한 판단

- 위쪽: 계급·이름·D-day·얇은 복무 막대만. 날짜·부대·보직 줄과 복무율 숫자는 뺐다(이름을 탭하면 내 정보). 이번 주 상황·효과는 아이콘만, 보험 칩은 숨김.
- 카드: 인물 이름이 두 번 나오던 것(본문 칩 + 이름표)과 NEW 도장 제거.
- 도크: 지금 못 쓰는 동료·PX·휴가 버튼은 숨긴다. PX가 열리면 튀어나온다. 훈련소에서는 가방·메뉴만.

### 10-4. 돌발 상황을 확실히 알게
- 카드보다 **빨간 경보 화면이 먼저**: "🚨 돌발 상황! N초 안에 골라라! 놓치면 → …". 탭하거나 2초 뒤에 시간이 간다(경보 중엔 선택이 안 돼서 억울하게 놓치지 않는다).
- 굵은 초 단위 막대, 카드 테두리 깜빡임, 마지막 2초 경고음·진동, 선택지 아래 "시간 안에 못 고르면: …".
- 결과 쪽지 머리에 "🚨 돌발 상황 대처 완료" / "⏱ 시간 초과!". 이번 주 상황이 시작되면 결과 쪽지에 큰 상자로.

## 11. 생존 게임 분석과 v6·v7 개편 — "이지선다는 훈련소에서만"

### 11-1. 진단
카드를 좌우로 넘기는 이지선다는 처음엔 빠르고 재미있지만, 같은 손동작이 18개월 내내 반복되면 따분해진다. 생존 게임의 재미는 **선택지 두 개 중 고르기**가 아니라 **스스로 움직이고, 모으고, 위험을 재고, 사람과 엮이는 데**서 나온다.

### 11-2. 시중 생존 게임에서 배운 것
| 게임 | 무엇이 사람을 붙잡나 | 전역각에 적용 |
|---|---|---|
| **Don't Starve** (Klei) | 어려움은 자원 부족보다 **시간 부족**에서 온다. 하루(8분)의 낮·밤 순환이 리듬을 만들고, 밤이 가장 위험하다. 탐험 → 채집 → 먹기 → 자기의 반복. 바깥 보상보다 스스로 하고 싶은 탐험을 살렸다. | 개인정비 시간은 **걸을수록 줄어드는 시계**. 22:00 점호 전에 생활관으로 돌아와야 한다. 지도 곳곳의 ✨ 반짝이는 줍기(탐험 보상). |
| **This War of Mine** (11 bit) | 거창한 줄거리 없이 **인물의 상태와 관계**에서 이야기가 생긴다. 낮(정비·제작)과 밤(위험한 수색)의 리듬이 게임의 뼈대. | 이야기는 강제 카드 대신 **사람에게 말을 걸어** 듣는다(📖). 낮 일과 → 개인정비 → 밤 사건의 하루 리듬. |
| **Stardew Valley** | 심기 → 거두기 → 팔기 → 도구 강화 → 더 심기처럼 **목표가 꼬리를 문다**. 계절, 관계가 깊어지는 맛, 매번 희귀템을 볼 수 있다는 기대. 일과가 '숙제'처럼 느껴지면 떠난다. | 파밍 → 조합(뽀글이 등) → 먹기/부탁 들어주기 → 특기 레벨 업의 사슬. 동료의 ❗ 부탁, 호감도. 일반·희귀·영웅·전설 득템. |
| **Project Zomboid · The Long Dark** | 대본이 아니라 **플레이어가 내린 결정**과 환경의 대결에서 긴장이 나온다. 영구 죽음 + 동적 사건 = 매번 다른 이야기. | 행보관(=포식자)이 순찰하며 앞을 본다. **보이는 데서 놀면 걸린다** → 숨어서 노는 잠입. 택배 도착 같은 그날그날 사건. 스탯 0·100이면 전역 실패(영구). |
| Reigns (참고) | 짧고 강한 선택의 연속 | **훈련소에만** 남겼다. 훈련소의 선택이 쌓여 특기·보직·자대가 정해진다. |

공통 뼈대: ① 시간·자원이 빠듯한 **하루 순환** ② 내가 움직여 찾는 **탐험과 득템** ③ 모은 걸 엮는 **제작** ④ 관계에서 나오는 **이야기** ⑤ 위험을 재는 **긴장**(포식자·밤) ⑥ 판을 넘어 쌓이는 **성장**(특기·짬·강화·수집).

### 11-3. 바뀐 구조
1. **훈련소 (카드)** — 13장 + 적성 카드 3장. 모든 선택지에 소질 점수(사격·체력·요리·행정·운전·의무·눈치). 배치 발표 때 **자대 배치 명령서**: 특기·보직·자대와 "훈련소에서 눈에 띈 모습".
2. **자대 (2D 월드)** — 위에서 내려다본 부대를 직접 걷는다(끌어서 조이스틱 · 톡 하면 그쪽으로 · 방향키).
   - 장소 12곳(생활관·행정반·사지방·의무실·연병장·체력단련장·사격장·뒷산·식당·PX·보급창고·정비고·위병소). 건물에 들어가면 지붕이 투명해지며 안이 보인다.
   - 물건 30여 개 = 행동: 꿀잠, 수양록, 혼자만의 시간, TV 쟁탈전, 수다, 조합, 냉동고 뽑기, 짬타이거, 근력 운동, 족구(미니게임), 영점 사격, 탄피 줍기, 서류, 커피, 휴가 신청, 인터넷 쇼핑, 자격증, 휴대폰, 창고 파밍, 몰래 꿀잠, 채집, 진료…
   - **특기 전용**: 특등사수 도전(사격), 특급전사 도전(체력), 특식 만들기(요리), 휴가 일정 조율(행정), 간부 수송 외출·장비 수리(운전), 동기 치료(의무). 쓸수록 특기 레벨 업(최대 5).
   - **행보관 순찰**: 빨간 부채꼴이 시야. 그 안에서 노는 행동을 하면 걸려 작업 당첨. 건물 안·밖이 다르면 안 보인다.
   - **사람**: 동료가 구역을 어슬렁거린다. 💬 수다(호감도), 📖 이야기(그 사람이 나오는 장면), ❗ 부탁(물건 건네기 → 호감도·다이아·휴가).
   - **줍기**: ✨ 반짝이(뒷산·연병장·사격장), 📦 택배(위병소). 한 턴에 6개까지.
   - **시간**: 걸으면 시간이 흐르고 행동은 1시간. 22:00 점호 때 생활관에 없으면 지각(신뢰·멘탈 감소).
3. **턴 = 2주(속성 복무 4주)**: 일과(자동·미니게임·가끔 카드) → 개인정비(2D) → 점호 → 밤 사건(40%) → 날짜가 흐름(월급·진급·계절). 강제 카드는 일과 22% · 밤 40%로 줄였다.

### 11-4. 균형 (시뮬레이션)
- 행동은 모두 **주고받기**(한쪽 오르면 다른 쪽 내림). 스탯을 식히는 행동(수양록, 혼자만의 시간)도 있다 — 100 초과도 실패라서.
- 처음엔 족구만 반복해 전우애 100으로 죽는 길이 있었다 → 미니게임도 결과를 미리 보여 주고 한 턴 한 번.
- 자동 일과가 신뢰를 계속 올려 '장기복무 권유'로 죽던 문제 → 일과는 체력·멘탈 위주로.
- 결과 (실력이 느는 가상 플레이어): 정상 복무 첫 판 약 60% 전역, 속성 복무 첫 판 약 50% → 10판 뒤 약 70%. 세심하게 하면 85~90%.
- 사람은 시뮬레이션과 달리 행보관 시야를 보고 피할 수 있어서 조금 더 쉬울 수 있다. 실제 테스트로 다시 맞출 것.
