# 제설각 v16: 눈싸움 벌러덩 · 간부 저격과 추격 · 밸런스 시뮬레이션 (2026-11)

> 요청: "눈싸움도 막 넘어지거나 그런 게 있어야 더 재밌을 듯. 간부한테 던지면 막 쫓아와서 잡히면 뭐가 깎이고. 그리고 밸런스 체크 — 수치들이 서로 잘 맞는지, 서로 다른 결정을 했을 때 더 재미있게 즐길 수 있는지. 다양한 시뮬레이션을 돌리면서 게임의 허점, 깨지는 글자 확인해봐."

## 1. 눈싸움 · 간부 저격

| | 전 | v16 |
|---|---|---|
| 분대원 맞히기 | 말풍선만 | **벌러덩** (0.9초 쓰러져 일 멈춤) → 75% 확률로 일어나서 받아친다 |
| 내가 맞으면 | 0.25초 멈칫 | **나도 벌러덩** (0.8초) |
| 행보관 맞히기 | "어떤 놈이야!!" + 칭찬 버프 날아감 | 벌러덩 → **쫓아온다** |
| 간부 (소대장·중대장·사단장) | 표적이 아니었다 | 표적 (버튼이 빨개지고 ⚠) → 벌러덩 → **쫓아온다** |
| 잡히면 | — | **얼차려** (2.5~3초 못 움직임) + 행보관: 상점 −1 (없으면 초코파이 −10%, 상한 있음) / 간부: **지적 +1** (등급 −5%p) + 상점 −1·−2·−3 (소대장·중대장·사단장) |
| 버티면 | — | 7초 동안 안 잡히면 **"따돌렸다!"** · 발견 "도주 성공" |

- 쫓는 속도는 내 걸음의 80%: 계속 움직이면 따돌리고, 멈추거나 벽에 막히면 잡힌다. 사륜바이크·트랙터에 타고 있으면 안 잡힌다
- 쫓는 사람은 나를 밀어내지 않는다 (처음엔 밀어내서 영영 못 잡았다 — 테스트에서 찾음)
- 선임 장난(이병·일병)도 보이는 분대원이 던지고, 받아치면 눈싸움
- 발견 10 → 12가지 (간부 저격, 도주 성공)

## 2. 밸런스 점검 — 어떻게 했나

`tests/snow-balance.js`: 가상 플레이어를 **보급 사는 전략 6가지 × 실력 3단계(효율 0.35·0.5·0.8) × 시드 3개 + 리어카 타기 + 특기 B** = 72판 (약 1분). `tests/snow-sim.js`에 `STRAT`·`RIDE`·`SPEC` 환경 변수와 `--json` 요약을 붙였다.

| 전략 | 무엇부터 사나 |
|---|---|
| default | 장비 → 분대원 → 싼 것 |
| tool / crew / perk | 장비 / 분대원 / 개인 장비·시설 먼저 |
| cheap | 늘 가장 싼 것 |
| none | 아무것도 안 산다 (장비 요청도 안 함) |

| 너무 쉬운가 | 가상 플레이어는 효율 0.2(딴짓 80%)에도 ★★★ | 그대로 — 봇은 지시서 순서·빙판·경례 판단을 한 번도 틀리지 않는다. 사람 난이도는 직접 해 보는 게 맞다 |

### 진급 특기

| 계급 | A | B |
|---|---|---|
| 일병 | 삽질 장인: 내 도구 범위 +25% (혼자 빠르게) | 분대 챙기기: 분대원 속도 +40% (분대와 함께) |
| 상병 | 짐꾼: 적재 +60% (왕복이 준다) | 인싸: 분대원이 지치지도 짱박히지도 않는다 |
| 병장 | 칼각: 지시서 기준 −5%p (★ 받기 쉽게) | 말년 여유: 작전 시간 +30초 |

가상 플레이어 기준 A가 3~9% 빠르다 (B의 '+30초'·'짱박힘 없음'은 봇이 안 하는 실수를 덮어 주는 쪽이라 사람에겐 더 쓸모 있을 수 있다). 처음엔 B가 10% 넘게 느려서 분대 챙기기를 +30% → +40%로 올렸다.
