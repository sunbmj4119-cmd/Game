# 제설각 v17: 오래 하게 — 처음은 빠르게, 뒤로 갈수록 어렵게 · 이번 주 작전 · 부재 보상 줄이기 (2026-11)

> 요청: "게임을 좀 오래 하게 해야 하는데 지금은 너무 쉽게 끝날 것 같아. 초코파이 주는 양이라든지 구역 확장이 너무 빨리 돼. 처음에는 빨리 되어도 뒤에 가서는 좀 어려워야 돼. 계속 똑같이 눈만 치우면 질릴 것 같은데 대비한 거 있니? 부재 시 주는 초코파이도 너무 많아. 적당히 줘."

## 1. 진행 곡선

| | v16 | v17 |
|---|---|---|
| 일병 | ★6 | ★6 (그대로 — 처음은 빠르게) |
| 상병 | ★20 | **★24** |
| 병장 | ★42 | **★60** |
| 전역 | ★75 | **★150** |
| 구역 (족구장·연병장·취사장 앞) | ★3 · 8 · 13 | ★3 · 8 · 15 |

| 작전당 ★ | 최대 3 | 최대 3 → 전역까지 **최소 50번** (전: 25번) |

**뒤로 갈수록 어렵게**
- 계급이 오를수록 날씨가 험해진다: 함박눈·폭설 확률 이병 25% → 일병 38% → 상병 50% → 병장 60%
- 계급마다 지시서 기준은 그대로 오른다 (85·88·92·95%), 구역도 늘어난다 (8곳까지)

**초코파이가 덜 빨리 쌓이게**
- 제설 요령(수입 업그레이드) +15% → **+8%**/단계
- 바깥 구역 눈 값 진입로 4→3 · 전차 주차장 6→4 · 위병소 8→5 · 헬기장 12→7
- 분실물·간부 경례·포상휴가 용돈이 날짜에 따라 끝없이 커지던 것 → 25일차까지만
- 후반 물건 값 올림: 살포기 15만→30만, 트랙터 50만→120만, 군용 제설차 150만→350만, 말년 병장 6만→12만, 행정병 16만→35만, 예비군 50만→110만, 제설차 250만→500만, 의무병·군가·분대 장비·눈조각 작업장 2~3배

**부재 보상**: 분대원 수입의 10%·최대 8시간 → **2.5%·최대 6시간**. 밤새 두면 작전 12번 분량이 들어오던 것이 많아야 작전 2번 남짓.

- 일병까지는 거의 같고(처음은 빠르게), 병장·전역은 두 배쯤 길어졌다
- 마지막 큰 장비(군용 제설차)가 전역 직전에 들어온다 (전엔 중반에 다 샀다). 남는 돈은 번 것의 16~19%
- 사람은 작전마다 보고까지 3~4분을 다 쓰고 ★★를 받는 날도 있어서 **전역까지 대략 50~60번, 3~4시간**. 그다음 전역 메달(보상 +10%)로 다시 시작
- 가상 플레이어는 판단이 완벽해 ★★★이 대부분이다. 사람에게 후반이 얼마나 어려운지는 직접 해 보는 게 정확하다

## 2. 질림 대비 — 원래 있던 것 + 이번에 넣은 것

원래 있던 변화: 날씨 4가지, 7일마다 사단장님 순시, 오늘의 특명(매일 다른 목표 9가지), 돌발 상황(폭설 경보·공병대 지원·불시 방문), 간부 순찰·고라니·출근 차량·처마 눈, 단계별로 열리는 기능, 이야기 13장, 발견 12가지, 탈것 3종, 진급 특기, 전역 후 다시 시작(메달).

**이번 주 작전 (새로)**: 8일차부터 7일마다 주제가 바뀌어 규칙을 한 가지씩 비튼다. 열린 기능 중에서만 나온다.

| 주제 | 무엇이 달라지나 |
|---|---|
| 혹한기 주간 | 그늘이 아닌 곳도 언다 (빙판 많이) · 보상 +25% |
| 사단장 순시 주간 | 매일 사단장님이 오신다 · 칼경례 상점 두 배 |
| 고라니 대이동 | 고라니 세 배 · 벌러덩 보상 두 배 |
| 폭설 주간 | 함박눈·폭설만 온다 · 보상 +40% |
| 체육대회 주간 | 족구 골 보상 세 배 (여섯 골까지) · 눈싸움하면 분대 사기 +15 |
| 정비 주간 | 탈것 기름 무한 · 탈것 속도 +20% |

생활관 소식 맨 위, 브리핑 특이사항, 작전 시작 배너에 나온다. 새 주가 되면 소식 줄이 강조된다.
