# 제설각 v11: "재미없다·조작이 힘들다·뭘 하라는 건지 모르겠다"에 대한 답 (2026-11)

> 피드백: "좀 재미없어. 조작도 좀 힘들고, 글자가 좀 작아서 뭘 어떻게 하라는 건지 전달이 약해. 시중에 인기 있는 게임들을 더 참고해서 수준을 높여줘. 게임에서 뭘 하는 건지, 무엇에서 재미를 느끼는지, 어디서 도파민이 터지고 어디서 반전이 있는지, 어떻게 풀어 나가는지, 무엇이 어떻게 배치돼 있는지. 메뉴 화면도 너무 간단하고 짜쳐. 고급진 좋은 게임이라는 느낌을 줬으면 좋겠어."

## 0. 한 줄 요약

**눈을 쓸면 등에 블록으로 쌓이고, 집하장에 쏟으면 초코파이가 지갑으로 날아간다. 빛나는 원 위에 서면 장비가 나오고, 마감 전에 다 치우면 ★, ★이 쌓이면 진급.**
버튼을 찾는 게임에서 **걸어 다니기만 하면 되는 게임**으로 바꿨다.

## 1. v10에서 왜 재미가 안 느껴졌나

| 피드백 | 원인 (v10) | v11 |
|---|---|---|
| 조작이 힘들다 | 처음 시점이 **1인칭**: 왼손은 걷기, 오른손은 고개 돌리기, 엄지로 행동 버튼. 한 손으로 못 한다 | **위에서 비스듬히 내려다보는 시점**이 기본. 화면 **아무 데나** 한 손가락으로 끌면 그 방향으로 걷는다 (화면 위 = 북쪽). 1인칭은 시점 버튼으로 |
| 버튼이 너무 많다 | 제설함 "염화칼슘 들기", 빙판 "뿌리기", 차 "밀기" 연타, 정비고 "기름통 받기", 행보관 위쪽 작은 버튼 "장비 요청"… 매번 멈춰서 버튼 | **지나가면 저절로**: 제설함 옆 → 포대를 든다, 빙판에 들어가면 → 뿌린다, 빠진 차 뒤에 붙어 있으면 → "영차!" 민다, 고라니 → 다가가면 도망, 자는 병장 → 옆을 지나가면 깨운다, 신병 → 다가가면 따라온다 → 구역에서 1초 멈추면 배치 |
| 뭘 하라는 건지 모르겠다 | 왼쪽 아래 작은 지시서 카드(12~13px)만 있다 | 화면 맨 위 **"지금 할 일" 한 줄** (22px): 할 일·부연 설명·진행 막대. 색이 급한 정도 (빨강 경례·차 / 노랑 붓기·보급 / 파랑 빙판 / 초록 보고·신병 / 남색 치우기). 땅 위 **노란 화살표**가 그곳을 가리킨다 |
| 글자가 작다 | HUD 대부분 12~15px | 지시서 14.5px, 알림 16px, 배너 40px, '지금 할 일' 22px, 행동 버튼 100px (경례는 150px) |
| 재미가 약하다 | 짐 게이지 숫자만 오른다. 부으면 숫자가 바뀐다 | **등에 블록이 쌓이고**(쌓일 때마다 음이 올라가는 "톡톡톡"), 집하장에 들어가면 블록이 **와르르 날아가고**, **+금액이 크게 튀고**, 초코파이 코인이 화면 위 **지갑으로 날아간다** |
| 반전이 없다 | 사건은 있지만(차·빙판·순시) 예고된 일정 | **폭풍 제설**(콤보 보상), **폭설 경보**, **공병대 제설차 지원**, **사단장님 불시 방문** — 작전마다 다르게 |
| 메뉴가 짜친다 | 로고 + 카드 + 버튼 4개 세로 나열 | **타이틀 화면** → **로비**: 3D 캐릭터 가운데, 위 내 카드(얼굴·계급장·★ 막대)와 지갑, 양옆 아이콘 버튼 10개(배지), 아래 진급 길·소식·금색 큰 "제설 출동" |

## 2. 참고한 게임과 가져온 것

| 게임 / 장르 | 무엇이 사람을 붙잡나 | 제설각 v11에 가져온 것 |
|---|---|---|
| **Burger Please! · Pizza Ready! (Supercent) — "아케이드 아이들" 장르** | 조이스틱 하나로 걷기 + **물건을 쌓아 나르기**가 핵심. 그 위에 업그레이드·확장 단계를 얹는다 ([Udonis 분석](https://blog.udonis.co/mobile-marketing/mobile-games/burger-please)). 아바타가 계속 움직이고, 자원을 모아 팔아 **새 구역을 열고** 캐릭터·환경을 올리는 장르 ([Homa Games](https://www.homagames.com/blog/arcade-idle-a-new-hybridcasual-genre-enters-the-game), [ironSource LevelUp](https://medium.com/ironsource-levelup/arcade-idle-creating-the-new-hybridcasual-genre-10d7f9dac21f), [Udonis: arcade idle](https://www.blog.udonis.co/mobile-marketing/mobile-games/arcade-idle)) | 한 손가락 끌기, **등에 쌓이는 눈 블록**, **원 위에 서 있으면 저절로**(보급·보고), 새 구역은 ★으로 열린다, 붓는 순간의 손맛 |
| **Brawl Stars (Supercell) 로비** | 가운데 캐릭터, 위 재화, 양옆 기능, 아래 큰 시작 버튼. 시각적 위계와 구획으로 많은 기능을 가운데를 가리지 않고 보여 준다 ([Pratt IxD 비평](https://ixd.prattsi.org/2025/02/design-critique-brawl-stars/), [Medium: What makes it great](https://medium.com/swlh/brawl-stars-what-makes-it-great-3861dfb169fb), [메인 메뉴 구성](https://samurai-gamers.com/brawl-stars/main-menu-guide/)) | **로비 배치 그대로**: 가운데 3D 캐릭터(천천히 도는 카메라), 위 카드·지갑, 왼쪽(기록) / 오른쪽(생활관) 아이콘 버튼과 빨간 배지, 아래 진급 길 + 반짝이는 금색 출동 버튼 |
| **Clash Royale** 진행 길 | 다음 보상이 늘 보이는 트로피 로드 ([The Rookies UX 분석](https://discover.therookies.co/2020/02/24/game-design-ux-best-practices-detailed-breakdown-of-clash-royale/)) | 로비의 **진급 길**: 이병 → 일병 → 상병 → 병장 → 전역, 각 단계 ★ 기준, 다음 단계가 "심사!"로 깜빡인다 |
| **PowerWash Simulator · Overcooked** (v10에서 이미) | 끝이 있는 한 판, 부분마다 "띵", 1~3★ | 그대로 유지: 하루 = 작전 한 번, 조각 완벽, ★ 판정 |

> 아케이드 아이들 자료 대부분은 퍼블리셔·광고 업계 블로그(2021~2023)라 숫자는 홍보 성격이 있다. 여기서는 숫자가 아니라 **조작과 손맛의 구조**만 가져왔다.

## 3. 게임에서 뭘 하나 (작전 한 판, 약 1~4분)

```
05:30 제설 비상 ── 끌어서 걷는다 → 빗자루가 알아서 쓴다 → 등에 블록이 쌓인다
                   └ 가득! → 노란 집하장에 들어간다 → 와르르 + 초코파이가 지갑으로
                   └ 초코파이가 모이면 → 노란 보급 원 위에 1초 → 다음 장비 (넉가래 → … → 군용 제설차)
        중간중간  └ 빙판(파랑) · 간부 순찰(빨강, 가운데 큰 경례 버튼) · 차 빠짐 · 폭설 경보 · 공병대 · 사단장님
지시서 다 하면  ── 초록 보고 원 위에 서 있기 → 검열 ★~★★★ (일찍 할수록 조기 퇴근 수당)
08:00           ── 시간이 다 되면 자동 검열
```

**풀어 나가는 법**: 화면 위 한 줄이 늘 "지금 할 일"을 말한다. 노란 화살표를 따라가면 된다. 뭘 해야 할지 모르는 순간을 없애는 게 목표.

## 4. 어디서 재미(도파민)가 터지나

| 순간 | 무엇이 보이고 들리나 | 왜 기분 좋은가 |
|---|---|---|
| 눈을 쓸 때 | 길이 드러나고, **등에 블록이 하나씩** 쌓인다. 쌓일 때마다 음이 반음씩 올라간다 | 내 노력이 몸에 보인다 (아케이드 아이들의 스택) |
| 집하장에 들어갈 때 | 블록이 줄줄이 날아가 쏟아지고, **+금액**이 크게 튀고, 코인이 지갑으로 날아가 지갑이 통통 | 한 번에 정산되는 보상. 만재(가득 채워 오면) +10% |
| 콤보 40·120·240… | **폭풍 제설!!** 배너, 화면 테두리가 금빛, 8초 동안 **눈 값 ×2 · 넉가래 범위 1.35배** | 콤보를 이어 갈 이유. 다음 폭풍까지 남은 수가 콤보 옆에 보인다 ("폭풍 제설까지 24") |
| 보급 원에 섰을 때 | 원이 차오르고 → **"넉가래 보급!"**, 화면 흔들림, 진동 | 장비가 바뀌면 바로 넓게 쓸린다 (체감되는 성장) |
| 조각·구역 완벽 | "완벽!" + 초코파이 + 상점 | 마지막 한 칸을 찾는 맛 (PowerWash) |
| 칼경례 | 큰 빨간 버튼을 빨리 누르면 "칼경례!" + 상점 | 짧은 반응 미니게임 |
| 검열 ★★★ | 별이 하나씩 쾅쾅쾅, 팡파르 | 하루를 판정받는다 |
| 진급 신고 | 계급장, "충성!", **편해지는 것 / 새로 할 수 있는 것** 목록 | 짬이 차면 편해진다 |
| 로비 | 배지가 통통 튀는 버튼(살 수 있는 보급 개수, 전화 "!", 휴가 "!") | 돌아올 이유가 늘 보인다 |

## 5. 반전 (작전마다 다르게)

| 반전 | 언제 | 무엇 | 대처 |
|---|---|---|---|
| **폭풍 제설** (좋은 반전) | 콤보 40·120·240·400·600 | 8초 동안 눈 값 ×2, 범위 1.35배, 금빛 화면 | 멈추지 말고 쓸어라 |
| **폭설 경보** (나쁜 반전) | 3일차부터, 날씨가 나쁠수록 자주 (15~80%) | 18초 동안 눈이 5배로 내린다. 치운 곳이 다시 덮인다 | 마감 급한 구역부터 지킨다 |
| **공병대 제설차 지원** (좋은 반전) | 4일차부터 35% | 제설차가 내 구역 한 줄을 싹 밀고 지나간다 | 보너스 |
| **사단장님 불시 방문** | 5일차부터 20% (순시 날 제외) | 예고 없이 사단장 등장 | 가운데 큰 빨간 "경례" 버튼 — 칼경례면 상점 |
| 출근 차량 빠짐 · 빙판 · 처마 눈 · 고라니 (v10) | 구역·날씨에 따라 | 감점 위험 | 지나가기만 하면 저절로 처리 (차 뒤에 붙기, 제설함 옆 지나가기) |

## 6. 화면 배치

```
타이틀                    로비 (생활관)                         작전
┌──────────────┐     ┌─────────────────────────┐     ┌──────────────────────────┐
│   전역각 외전   │     │[얼굴] 상병 홍길동   🍫3,914│     │[계급]05:36  (짐 4/60)  🍫308 상1│
│              │     │ 조장·3일차 ★20/42  [상]19 │     │┌ ● 넉가래 받을 수 있다!   ┐│
│   제 설 각     │     │[교범]              [보급]11│     │└ 보급 원 위에 서 있기 ───┘│
│ 05:30 제설 비상 │     │[훈장]   (3D 캐릭터)  [PX] │     │        ⏸ 📦 📷 🔍       │
│              │     │[수첩]   천천히 도는  [전화]! │     │  콤보 x16 · 폭풍까지 24    │
│              │     │[꾸미기]  카메라    [체력] │     │  (행보관 말풍선 · 알림)     │
│              │     │[설정]              [휴가]! │     │      🧍 ← 노란 화살표 →   │
│ 화면을 눌러 시작 │     │ 이병─일병─[상병]─병장─전역 │     │   (빛나는 원: 보급 / 보고) │
│              │     │ 지난 작전 ★★★ · 내일 눈  │     │[작업 지시서]      (행동)  │
└──────────────┘     │ [   제설 출동  3일차   ]  │     └──────────────────────────┘
                     └─────────────────────────┘
```

- **위**: 계급·시계 / 짊어진 눈(링) / 초코파이·상점 → **'지금 할 일' 한 줄** → (구역 안에서 70% 넘으면) 조각 진행 막대 → 작은 버튼(정지·상자·시점·남은 눈)
- **가운데**: 알림 줄(폭풍·폭설·콤보·배너·말풍선·알림) — HUD 높이에 맞춰 바로 아래에서 시작
- **땅 위**: 빛나는 원 2개(행보관 옆 보급 원·보고 원) + 이름표(장비 이름·값·"일병부터"), 노란 화살표, 목표 지점 링
- **아래**: 왼쪽 작업 지시서 / 오른쪽 행동 버튼 (사람 앞에서만 나타난다). 급한 경례는 가운데 큰 빨간 버튼 (지시서는 잠시 숨김)

## 8. 바뀐 파일

- `js/snow/data.js` — `PADS`(보급·보고 원), `FEVER`, `TWIST`, 대사, 할 일 안내 문구를 v11 조작으로
- `js/snow/sim.js` — 폭풍 제설(콤보 → 값·범위), 폭설·공병대·불시 방문 일정과 처리
- `js/snow/act.js` — `pads()`, `auto()`(지나가면 저절로), `objective()`('지금 할 일'), 행동 후보는 사람만 (간부·행보관·분대원·제설차·짬타이거)
- `js/snow/view3d.js` — 위에서 보는 기본 시점, 등에 쌓이는 블록·날아가는 블록, 빛나는 원과 이름표, 땅 위 화살표·목표 링, 공병대 제설차, 폭풍 반짝이, 로비 카메라(`lobby()`), `screenOf()`
- `js/snow/view.js` — 2D에서도 원·화살표, `screenOf()`
- `js/snow/sfx.js` — 쌓이는 소리(음이 올라간다), 폭풍 제설 소리
