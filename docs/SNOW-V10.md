# 제설각 v10: 비슷한 게임 비교 분석과 "제설 작전" 개편 (2026-11)

> 요청: "군인들의 제설을 게임으로 현실화한 게임을 재미있게 플레이하고, 군대적 요소로 흥미를 느끼고, 지속가능하게 노력하면 성취감과 점점 계급이 상승하고 그에 따른 보상과 점점 난이도도 쉬워지고 더 많은 것들을 하게 되는 구조. 비슷한 게임들을 여러 개 비교 분석해서 보완하고, 이상한 상호작용 말고 실제로 있을 만한 상호작용, 좀 더 집중할 수 있는 구조로."

## 1. 냉정한 진단: v9의 문제

| | 문제 | 왜 문제인가 |
|---|---|---|
| 1 | **끝이 없는 하루** | 3분짜리 하루가 계속 이어지고, 언제든 상점·임무·심부름·뽑기·족구·전화가 끼어든다. "지금 뭘 해야 하지?"가 없다 |
| 2 | **동시에 도는 것이 너무 많다** | 화면에 할 일 카드, 행정반 임무, 심부름 2개, 손에 든 물건, 버프, 분노 ★, 운전 게이지, 눈덩이 버튼, 보급 버튼이 한꺼번에 뜬다 |
| 3 | **GTA식 상호작용** | 중대장님 차 탈취, 전차 만지면 분노, 행보관 추격 → **엎드려 뻗쳐**(본편이 피하는 가혹행위 소재), 행보관에게 눈덩이, 제설 헬기, 자판기에서 다이아 |
| 4 | **계급이 숫자일 뿐** | 누적 초코파이가 기준을 넘으면 진급. 병장이 돼도 하는 일은 이병과 똑같다. "짬이 차면 편해진다"는 군대의 핵심 감각이 없다 |
| 5 | **노력과 성취의 연결이 약하다** | 잘 치우든 못 치우든 초코파이만 쌓이면 진급. 오늘 잘했는지 판정해 주는 순간이 없다 |
| 6 | **현실 제설의 재미가 빠져 있다** | 마감(아침 식사·간부 출근), 우선순위(진입로 먼저), 빙판, 염화칼슘, 차가 빠지는 진입로, 처마 눈 같은 진짜 제설의 긴장이 없다 |
| 7 | **숨은 버그** | 행보관이 시작 자리(330,290)에서 나무 충돌 반경 안에 박혀 한 번도 움직이지 못했다 |

## 2. 비슷한 게임 비교

| 게임 | 핵심 루프 | 사람을 붙잡는 것 | 비판·한계 | 제설각에 가져온 것 |
|---|---|---|---|---|
| **PowerWash Simulator** | 일감(Job) 하나 → 진행률 % → 다 닦으면 끝. 일감마다 별, 별이 쌓이면 다음 일감 | 바로 보이는 손맛, 부분마다 "띵", 끝이 있는 한 판, 다시 하기(보상은 25%) | 타이머·적이 없어 긴장은 약함 | **하루 = 작전 한 번**(시작과 끝), 지시서 줄마다 완료 도장, ★로 다음 단계 |
| **Moon Sweepers** | 칫솔로 담기 → 나르기 → 팔기 → 장비·차량 → 공장·로봇 | 세 단계 손맛(손 → 차 → 자동화), 치운 곳이 남는다 | 초반 진척 벽, 2시간이면 거의 다 연다 | 퍼 담기·나르기·붓기와 분대원 자동화는 그대로. 콘텐츠 벽은 **계급별 역할 변화**로 |
| **Snow Plowing Simulator** | 계약 → 제설 → 새 동네가 열림 | 눈 치우는 느낌 자체가 만족스럽고 차분하다 | 반복적, 버그·최적화·저장 불만 (Steam 평가 "복합적") | 계약 = **작업 지시서**. 반복을 깨는 장치(마감·빙판·차 빠짐·순시)를 넣었다 |
| **Police Simulator: Patrol Officers** | 근무(shift) → 근무 점수 → 근무 별(duty star) → 새 지구·차량·임무 | 현실 절차(신분증·딱지)를 그대로 하는 맛, 별로 열리는 단계 | 반복, 늦게 열리는 콘텐츠 | **작전 점수 → ★(근무평정) → 새 구역·장비·진급**. 권한 남용 감점(Conduct)처럼 **지적**(경례 안 함) 감점 |
| **This Is the Police** | 경찰서장: 매일 출동 배치, 경찰관의 피로·전문성·휴가 요청 관리, 시장의 압박 | 사람을 굴리는 결정, 매일 다른 사건 | 설명 부족, 관리가 버겁다 | **분대원 사기**(짱박힘), **상병부터 브리핑에서 작업 분담**, 위에서 내려오는 지시(07:30 출근 차량, 사단장 순시) |
| **Overcooked** | 3~5분짜리 판, 주문을 쳐내면 점수, 1~3★ | 1★은 쉽고 3★은 연습해야 한다. 판 사이에 전략을 짠다 | 혼자 하면 별 기준이 빡빡하다 | **★ 기준**: 대충 해도 ★, 마감·경례·빙판까지 챙겨야 ★★★. 판 사이 생활관에서 준비(PX·배치) |
| **Euro Truck Simulator 2** | 직접 운전 → 돈 → 기사 고용·차고 확장 → 내가 안 몰아도 회사가 돈을 번다 | 내가 하던 일을 남이 하게 되는 성장 | 관리 시스템은 얕다 | **이병은 직접, 병장은 지휘만**. 분대원이 쌓일수록 내 몫이 줄어든다 |
| **Leaf Blower Revolution** | 범위·도구가 커지고 새 구역마다 새 것 | 숫자가 커지는 증분형 쾌감 | 후반 반복 | 장비 8단계는 유지, 대신 **계급이 돼야 받는 장비**(좋은 장비는 짬 순서) |

공통점:
1. **한 판에 시작과 끝이 있다** (PowerWash 일감, Overcooked 판, Police Sim 근무) → 집중이 생긴다
2. **판 끝에 판정(별)이 있고, 별이 다음 단계를 연다** → 노력과 성취가 바로 연결된다
3. **성장하면 하는 일 자체가 바뀐다** (ETS2 운전수 → 사장, This Is the Police 서장) → 질리지 않는다
4. **현실 절차가 재미가 된다** (Police Sim의 신분증 확인, Snow Plowing의 계약)

## 3. 바꾼 구조: 하루 = 제설 작전 한 번

```
생활관(저녁)  ──출동──▶  제설 비상 브리핑  ──▶  작전 05:30~08:00 (약 4분)  ──보고/08:00──▶  행보관 검열(★)  ──▶  (진급 신고)  ──▶  생활관
 PX 준비물·공중전화        누가 지시하나(계급마다)     작업 지시서: 구역마다 기준%와 마감          지시서 이행·지적·빙판·차 빠짐       ★ = 근무평정
 체력단련·보급·인원        날씨·특이사항               행보관에게 장비 요청 / 다 하면 보고         초코파이·상점·보급 상자              상점 10 = 포상휴가
 포상휴가·전역 신고        (상병부터) 작업 분담                                                    새 담당 구역
```

- **작전 중엔 작전만**: 보급 버튼·눈덩이 버튼·임무·심부름·뽑기·족구가 사라졌다. 작전 중에 장비가 필요하면 **행보관에게 가서 요청**한다(현실 그대로).
- **작업 지시서**(왼쪽 아래 카드): 마감 순서대로 3줄, 지금 할 것은 ▶. 빙판·차 빠짐·보고 대기가 있으면 빨간/초록 한 줄. 처음엔 할 일 안내 한 줄.
- **마감에 이유가 있다**: 생활관 앞 길 07:00(아침 식사 이동로), 취사장 앞 07:00(배식), 부대 진입로 07:30(간부 출근 차량), 위병소 앞 07:30(출근 차량 통과), 연병장 08:00(일과 시작 집합), 헬기장 08:00(응급 후송 대비)…
- **보고하면 끝**: 지시서를 다 하면 행보관이 다가온다. 일찍 보고할수록 **조기 퇴근 수당**.
- **검열 결과**: 마감 지킨 구역은 두 배 무게. 지적(경례 안 함) −5%, 출근 차량 빠짐 −10%, 빙판 방치 곳당 −5%, 보고·전부 100%는 가점. 50%↑ ★, 80%↑ ★★, 97%↑ ★★★.
- 작전 도중 꺼도 시계·치운 곳·끝낸 줄이 저장되고 "작전 이어하기"로 돌아온다.

## 4. 계급 = 역할 ("짬이 차면 편해진다")

진급은 초코파이가 아니라 **근무평정(★ 합)**. 기준을 넘으면 다음 작전이 **진급 심사**(기준 95%, ★★ 이상 합격). 진급하면 **진급 신고** 화면에서 역할·편해지는 것·새로 할 수 있는 것을 보여 준다.

| 계급 | ★ | 내 역할 | 편해지는 것 | 새로 할 수 있는 것 |
|---|---|---|---|---|
| 이병 | 0 | 막내 — 시키는 구역을 직접. 말년 병장이 "야 막내, 넌 생활관 앞" | — (선임 눈덩이 장난 60%, 잔소리) | 싸리비 → 넉가래 → 대형 넉가래(행보관 보급), 경례·관등성명 |
| 일병 | 6 | 일꾼 — 맡은 구역을 알아서 | 눈덩이 장난 30%, 분대원 정원 1 → 3 | 2인용 넉가래, 동기·취사병, 염화칼슘 |
| 상병 | 20 | 조장 — 작업 분담을 정하고 조원을 굴린다 | 눈덩이·잔소리 끝, **브리핑에서 조원 배치**(걸어가서 안 데려와도 된다), 정원 7 | 보행식 제설기·염화칼슘 살포기(빙판 자동 처리), 말년·행정병, **구령대에서 구령** |
| 병장 | 42 | 분대장 — 지휘만 한다. 몸은 난로 옆에 | **작업 2배속**(말년 특권), 정원 16 | 트랙터·군용 제설차, 예비군·제설차 지원, 전역 신고(★75) |

구역도 사지 않는다. ★이 쌓이면 중대에서 더 맡긴다: 족구장 ★3 → 연병장 ★7 → 취사장 앞 ★12 → 부대 진입로 ★18 → 전차 주차장 ★26 → 위병소 앞 ★36 → 헬기장 ★50. 할 일이 계속 늘지만, 그만큼 분대원과 장비가 대신 해 준다.

## 5. 상호작용: 이상한 것 → 실제로 있을 법한 것

| 뺀 것 | 왜 | 대신 넣은 것 (현실 근거) |
|---|---|---|
| 중대장님 차 탈취 | 현실에서 있을 수 없음 | **07:30 출근 차량**: 진입로 가운데 바퀴 자리를 안 치웠으면 **차가 빠진다** → "차 밀기" 연타, 근처 분대원도 와서 민다. 치워 두면 한 번에 올라가고 상점 |
| 행보관 분노 ★·추격·엎드려 뻗쳐 | 가혹행위 소재, GTA식 | **지적**: 간부에게 경례를 안 하면 지적 1건(등급 −5%). 소대장은 서운해할 뿐 |
| 전차 만지기 분노, 태극기·눈사람 경례 | 의미 없는 개그 | 전차 주차장은 "전투 장비 점검 전"이라는 마감이 있는 구역 |
| 눈덩이 던지기 버튼, 인력 맞히기 | 작업 중 장난 | **선임 눈덩이 장난을 당하는 쪽**(이병만, 일병은 가끔, 상병부터 없음) |
| 운전 교대·트랙터 몰기 | 운전은 운전병이 | 제설차는 **"따라와" → 구역 배치**, 기름 떨어지면 **정비고 기름통** |
| 제설 헬기(도구), 헬기 하강풍 | 예산 밖 | 헬기장은 **응급 후송 대비** 구역 |
| 행정반 랜덤 임무(태극기 경례·눈싸움 3번…) | 맥락 없음 | **작업 지시서** |
| 심부름(짬밥·간식·편지) | 05:30 제설 중엔 없다 | 사기 관리는 초코파이·구령·PX 준비물로 |
| 자판기 뽑기 다이아, 철봉·공중전화(작전 중) | 작전과 무관 | 공중전화·체력단련은 **생활관 저녁** (전화는 하루 한 번, 턱걸이는 내일 적재 +25%) |
| PX 버프(작전 중) | 새벽엔 PX가 안 연다 | **저녁에 사 두는 준비물**: 핫팩, 맛스타, 냉동 핫바, 초코파이 상자, 컵라면 |
| 상점에서 구역 확장 | 구역은 중대가 맡긴다 | ★으로 배정 |
| 다이아(간부 계급장) 화폐 | 이상함 | **상점**(상벌점 제도). 모아서 **포상휴가**(상점 10 = 1일: 가족 장면 + 용돈 + 보급 상자 + 분대 사기 100) |
| 고라니에 받히면 짐을 다 쏟음 | 과한 벌 | 고라니는 들어오면 쫓아낸다. 받히면 잠깐 넘어질 뿐. 하루 최대 2마리, **깡통 줄**로 줄인다 |

새로 넣은 현실 요소:
- **빙판**: 그늘(생활관 앞 오른쪽)·배식구 앞·진입로 비탈·위병소 왼쪽은 다 치우면 **언다**(푸르게 번들번들). 그 위를 걸으면 미끄러진다. **제설함**(초록 상자, 도로변 염화칼슘 보관함)에서 포대를 들고 가서 뿌린다.
- **처마 눈**: 먼저 "우두둑" 소리와 경고 → 1.6초 뒤 떨어진다. 피할 수 있다.
- **행보관 보급**: "행보관님, 넉가래 하나 주십시오!" — 좋은 장비는 계급 순서.
- **작업 완료 보고**: "충성! 제설 작업 완료했습니다!"
- **간부 보고**: "지시받은 5개 구역 중 3개 완료, 나머지 진행 중입니다!"
- **구령대**(상병부터): 분대원 +25%, 사기 +25.
- **선임 잔소리**(이병): "야 막내, 거기 덜 됐잖아."
