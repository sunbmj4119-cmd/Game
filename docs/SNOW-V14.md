# 제설각 v14: 비스듬한 3인칭 + Moon Sweepers식 크기·간섭 정리 + 재미 요소 (2026-11)

> 요청: "게임 화면을 너무 위에서 비추고 있어. 적당히 옆에서 보는 3인칭으로. Moon Sweepers를 참고해 아이템이나 게임에 영향을 주는 요소들의 간섭이나 크기 영향을 분석해서 보완해줘. 예전엔 눈덩이 던지기 같은 재미 요소가 있었는데 그런 걸 넣어 주면 좋겠어. '아 이런 것도 할 수 있네' 하는 재미. 고라니를 눈 맞혀서 쓰러뜨리기, 탈것도."

## 1. 카메라: 위에서 → 뒤에서 비스듬히

| | v11~v13 | v14 |
|---|---|---|
| 내려다보는 각도 | 61° (거의 정수리만 보임) | 34° (얼굴·몸·앞길이 보임) |
| 내 캐릭터 위치 | 화면 가운데 | 화면 아래쪽 가운데 (앞이 더 많이 보인다) |
| 방향 | 화면 위 = 북쪽 | 그대로 (끄는 방향 = 걷는 방향). 카메라가 캐릭터 따라 돌면 한 손 조작에서 방향이 헷갈려서 고정 |

비스듬해지면서 생긴 문제와 처리:
- 내 앞(카메라 쪽) 건물이 나를 가린다 → 원래 있던 반투명 처리 유지
- **나무가 나를 가린다** → 내 앞쪽 나무만 납작하게 눌러 둔다 (지나가면 다시 선다)
- 먼 곳 이름표(보급 원 등)가 화면 위 HUD로 올라간다 → 3D 이름표는 HUD 아래에서만 보인다
- 폰 세로 화면은 옆이 좁다(좌우 약 ±80px) → 카메라를 조금 뒤로 빼고, 눈덩이 사거리도 화면 안에 맞춤(고라니 150)

## 2. Moon Sweepers와 비교: 아이템·요소의 크기와 간섭

> 이 환경에선 위키 본문이 열리지 않아 검색 결과 요약과 예전 분석([MOONSWEEPERS.md](MOONSWEEPERS.md))을 근거로 했다. 숫자는 패치마다 다를 수 있다.

| 요소 | Moon Sweepers | 제설각 v13 | v14에서 |
|---|---|---|---|
| **도구 폭** | 브러시마다 폭이 넓어진다 (Wide 약 65.9cm → Extra Wide 약 98.8cm). 공략: 초반 싼 브러시는 거의 차이 없으니 건너뛰라 | 싸리비 11 → 군용 제설차 70. 넓을수록 좋기만 함 | 손 도구는 그대로. 대신 **탈것**은 폭·적재가 크면 몸집도 크다 |
| **적재량** | 통 업그레이드 약 3→6kg, 압축기 +15% (모든 도구) | 도구마다 정해짐 | 리어카 ×3, 사륜바이크 ×1.5, 트랙터 ×4 |
| **차량** | 차량 5종(밀대 청소기 $300 → 탑승형 $1,000 → 수송 밴 → 달 청소차 → 메가 진공). 차량마다 속도·오버드라이브·폭(+25/50/75%)·하역 속도·전조등 업그레이드 | v10에서 "운전은 운전병이"라며 직접 타는 것 삭제 (도구 7·8단계만 차) | **세워 둔 탈것 3종**을 직접 탄다 (아래 표) |
| **크기의 간섭** | (공략에서 확인 못 함) | 몸집은 누구나 같음 (반지름 6) | 탈것은 몸집이 커서 **좁은 틈을 못 지나간다** — 구령대 옆 틈은 걸어서는 지나가고 트랙터는 못 간다. 넓게·많이·빨리 대신 '어디로 갈 수 있나'가 대가 |
| **방해(간섭)** | 거의 없다 (힐링형) | 일병부터 작전 4분에 방해 8.4번 (분당 2.1) — 처마 눈 4.1, 고라니 2, 간부 2 | 처마 눈 55초 → 95초 간격 (작전당 약 2.7번, 분당 1.7). "처마 눈! 피해" 알림은 **근처일 때만** |
| **방해를 재미로** | — | 선임 눈덩이 장난 = 그냥 기절 0.5초, 고라니 = 쫓아내는 대상 | 장난은 **보이는 분대원이 던진다 → 받아치면 눈싸움**. 고라니는 **표적**(두 방이면 벌러덩, 보상) |
| **놀거리** | 제트팩, 점프, 중력 부츠, 친구 태우고 차 몰기 | v10에서 '현실적이지 않다'고 눈덩이·족구·탈것을 뺐다 | 눈덩이·족구·눈천사·드리프트·탈것 + **발견 수첩** |
| **끝내기** | 구역에 1% 이하 남으면 완료 | 지시서 기준 85~95%, 100%는 보너스 | 그대로 |

## 3. 탈것 (세워 둔 자리에서 '타기', 아무 데서나 '내리기')

| 탈것 | 언제 | 앞날 폭 | 적재 | 속도 | 몸집 | 기름 | 특징 |
|---|---|---|---|---|---|---|---|
| 리어카 (집하장 옆) | 일병 | 내 도구 그대로 | ×3 | ×0.8 | 11 | 없음 | 짐칸에 눈이 쌓여 보인다. 왕복이 확 준다 |
| 사륜바이크 (보고 원 옆) | 취사장 앞(★13) | 24 | ×1.5 | ×1.6 | 10 | 70초 | 빙판에선 미끄덩 (드리프트). 고라니가 부딪혀도 안 넘어진다 |
| 트랙터 (정비고 앞) | 상병 | 44 | ×4 | ×1.0 | 16 | 100초 | 아주 넓게 민다. 좁은 길은 못 간다 |

- 기름이 떨어지면 저절로 내리고, 그 자리에 남는다. **정비고 앞에 세우면 기름이 찬다** (다음 작전엔 원래 자리에 가득)
- 타고 있으면 왼쪽 아래 「타고 있다 · 기름」 (누르면 내린다). 다른 할 일이 없을 땐 행동 버튼도 '내리기'
- 단계별 공개(v13)에 맞춰 열리면 브리핑 "새로 생김"에 한 줄

## 4. "아 이런 것도 되네" — 발견 10가지

처음 하면 화면에 **"발견! ○○" + 상점 1**, 생활관 **수첩**에 모인다(못 찾은 건 ??? + 힌트).

| 발견 | 하는 법 |
|---|---|
| 첫 눈덩이 | 족구장(구역 B)부터, 근처에 고라니·분대원·행보관이 있으면 오른쪽에 **눈덩이 버튼**. 누르면 알아서 조준 (움직이는 고라니는 앞을 보고 던지고, 날아가며 살짝 휜다) |
| 고라니 벌러덩 | 고라니에게 두 방. 한 방 맞으면 1.6초 비틀거려서 두 번째도 맞힐 수 있다. 3.5초 누워 있다가(@_@) 비틀비틀 도망. 초코파이 보상, 분대원 "나이스 샷!" |
| 고라니 쓰담쓰담 | 누운 고라니 옆으로 가면 |
| 눈싸움 | 분대원을 맞히면 60% 확률로 받아친다 / 선임이 던지면 받아친다 |
| 간 큰 놈 | 행보관을 맞히면 "어떤 놈이야!!" (칭찬 버프가 날아간다). 다른 표적이 없을 때만 고른다 |
| 족구 한 골 | 족구장 공을 몸으로 밀어 네트를 넘기면 (탈것으로 밀면 더 세게) |
| 눈천사 | 눈밭에서 5초 가만히 → 벌러덩 (누운 모습만, 끌면 바로 일어난다. 작전당 한 번) |
| 첫 운전 | 탈것 타기 |
| 빙판 드리프트 | 사륜바이크로 빙판 위를 달리면 |
| 짬타이거 집사 | 고양이 쓰다듬기 |
