# 제설각 설계

> "그럼 차라리 제설하는 것으로 해서 한국인들의 노동력을 착취하는 게임을 해보자. 처음에는 도구도 조그마한 거 줘서 범위가 작다가, 점점 도구도 업그레이드하고 사람도 채용하면서 재미를 느끼는 거지."

[생존 게임 재분석](SURVIVAL-ANALYSIS.md)에서 정리한 흥행작의 공통점(30초 안의 손맛, 점점 강해지는 맛, 짧은 판 + 판 밖의 성장, 분명한 큰 목표)을 한국 군대 제설에 맞춘 증분형(incremental) 게임이다.

## 한 판의 흐름
1. **작업** (약 60초 + 핫팩): 한 손으로 걷는다. 도구는 자동으로 앞쪽 눈을 민다. 눈은 계속 내려 치운 곳에 다시 쌓인다.
2. **행보관 검열**: 제설률로 특급(95%+) · 양호(목표 이상) · 미흡(50%+) · 재작업. 특급 +40%, 양호 +20% 보너스. 대대장 순시 날은 목표 90%, 보너스 두 배. 98%를 넘기면 바로 퇴근하고 남은 시간만큼 보너스.
3. **보급·인력 관리**: 초코파이로 도구, 인력, 보급(아이젠·핫팩·맛스타·칭찬·군가 스피커·장비), 구역 확장.

## 성장 사슬
- 도구가 넓어질수록 카메라가 멀어진다 (싸리비: 세계 290px 너비 → 헬기: 지도 전체)
- 계급은 누적 초코파이로: 일병 3천, 상병 4만, 병장 20만. 계급마다 새 인력
- 구역이 늘면 칸당 보상이 커지지만(1 → 8) 같은 시간에 목표를 넘기기 어려워진다 → 인력과 도구가 필요
- 전역: 병장 + 누적 80만. 메달 = √(누적/4만), 메달마다 모든 보상 +10%

## 페이싱 (tests/snow-sim.js, 80% 효율 가상 플레이어)
| 시점 | 무엇 |
|---|---|
| 1일차 | 마당 확장 |
| 2일차 | 넉가래, 첫 후임 |
| 3일차 | 일병 |
| 5~7일차 | 연병장, 대형 넉가래·쌍넉가래, 동기 |
| 7일차 | 상병 |
| 8~12일차 | 진입로 |
| 14일차 | 병장 |
| 20일차 전후 | 말년 병장, 위병소 앞, 손수레 제설기 |
| 26~28일차 | 전역 가능 |

하루가 1분 남짓이라 첫 전역까지 약 40분.

## 군대 개그 (일부)
- 후임: "초코파이 하나면 영혼까지 갈아 넣는다."
- 말년 병장: 작업 시간의 40%는 잔다. 행보관이 가까이 오면 "병장! 자냐?!" 하고 깨운다.
- 예비군 아저씨: "동원훈련 왔다가 끌려왔다." / "우리 땐 삽 하나로 다 했어"
- 쉬는 동안 보상: "쉬는 동안에도 인력은 일한다. 그게 군대다."

## 파일
- `snow.html`, `css/snow.css`
- `js/snow/data.js` 지도·도구·인력·보급·계급·날씨·대사
- `js/snow/sim.js` 규칙 (DOM 없음, Node 테스트 가능)
- `js/snow/view.js` 캔버스: 땅·눈 층(바뀐 칸만 다시 그림)·사람·차량·입자·카메라·입력
- `js/snow/ui.js` 타이틀·HUD·검열·상점·진급·전역·쉬는 동안 보상
- `js/snow/sfx.js` 효과음 합성 (넉가래 긁는 소리, 호루라기, 도장, 나팔)
- 행보관 얼굴은 본편 `js/art.js` + `js/data/chars.js`의 강삽질을 그대로 쓴다
