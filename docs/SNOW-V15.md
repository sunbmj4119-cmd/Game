# 제설각 v15: 폰에서 직접 해 보고 나온 불편 고치기 (2026-11)

> 요청 (휴대폰 화면 사진과 함께): "글자가 깨지고, 후임이 들어왔을 때 투명해져서 안 보이고, 눈을 한곳에 모으는 건 구역이 넓어지면 너무 비효율적이야. 몇 시 몇 분 같은 군대 디테일은 투머치 — 어떤 정보를 확실히 주면 되는지만. 중간 화면은 선택지가 너무 많아서 번잡해."

## 1. 고친 것

| 문제 | 원인 | 고친 것 |
|---|---|---|
| **글자가 두세 글자씩 꺾임** (보급 → 인원 카드) | 오른쪽 버튼 글자("정원 1명 (진급하면 늘어남)")가 길어서 설명 칸이 아주 좁아졌다 | 버튼은 최대 112px에 줄바꿈 허용, 설명 칸이 늘 더 넓다. 잠긴 버튼 글자 짧게("정원 꽉 참"), 설명은 두 줄까지 |
| **새 후임이 안 보임** | 3D 사람 모델을 작전 시작할 때만 만들었다 → 작전 중에 배치한 신병은 모델이 없어 사라졌다 | 사람이 늘면 그 자리에서 모델을 만든다 (테스트: 배치하면 바로 보인다) |
| **구역이 넓어지면 붓기가 비효율** | 집하장이 생활관 앞 한 곳 + 구역마다 '양동이 릴레이'를 따로 사야 했다 | **구역을 맡으면 그 구역 옆 집하장이 저절로 생긴다** (8곳). 화살표·"지금 할 일"은 가장 가까운 집하장으로. 릴레이 구매 항목은 없앴다 |
| **시각이 너무 많음** (05:30, 07:00까지, 07:20 전, 08:00) | 군대 일과를 그대로 옮겼다 | 시계 대신 **남은 시간 하나** (`2:00 남음`). 마감은 시각 대신 **"곧 마감!"/"늦었다!"** 를 그 순간에만. 브리핑은 "위에서부터 순서대로", 결과는 "1:57 남기고 보고". 특명 "07:20 전 보고" → "1분 넘게 남기고 보고" |
| **중간 화면이 번잡** | 보급 탭 9개(장비·인원·개인 장비·시설·구역·꾸미기·수첩·훈장·전역), 생활관 버튼 10개, 설명 문단 | 아래 2번 |
| (덤) 초코파이 칸이 '톡' 커질 때 화면 밖으로 5px | 가운데 기준으로 커졌다 | 오른쪽 기준으로 커진다 |

## 2. 중간 화면 정리

**보급** (탭 9개 → 3개)
- **장비 · 인원 · 강화**(개인 장비 + 시설). 구역 탭은 뺐다 (★으로 맡는 것이라 살 게 없었다)
- 꾸미기 · 수첩(훈장 포함) · 전역은 생활관 버튼에서 **따로 연다** (탭 줄 없이)
- 탭마다 붙어 있던 설명 문단을 뺐다
- **잠긴 것은 첫 하나만** 보이고 나머지는 "잠긴 것 N개 더 보기"로 접는다
- 인원 탭 머리: 남색 상자에 다섯 줄 → "분대원 n명 · 정원 · 사기 막대" 한 덩어리. 상점으로 부르는 지원(전원 초코파이·대대 지원)은 "상점으로 지원 부르기 ▾"로 접었다
- 아래 버튼 "작업 계속" → "생활관으로" (실제로 하는 일 그대로)

**생활관 버튼** (10개 → 보통 6~7개)
- 교범 → 설정 안으로
- 훈장 → 수첩 안으로
- 전화 → 오늘 걸 수 있을 때만, 체력단련 → 오늘 안 했을 때만, 휴가 → 상점이 10개 모였을 때만
