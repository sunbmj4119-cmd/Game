# 제설각 v13: 단계별 공개 + 덜 읽기 + 폰 화면 더블체크 (2026-11)

> 요청: "요소들이 너무 많아서 핸드폰으로 게임하기가 너무 번잡해졌어. 볼 것도 너무 많고, 너무 읽을 게 많아. 요소들은 구역이 확장되거나 레벨이 오를 때마다 추가되도록 하고, 핸드폰 화면에서 가려지거나 불편한 점 없는지 더블체크해줘."

v12 위에 얹었다. 규칙·밸런스는 그대로 두고, **언제 보이느냐**와 **얼마나 읽느냐**만 바꿨다.

## 1. 무엇이 문제였나 (v12, 360×640 폰)

| 장면 | 화면이 UI로 덮인 비율 | 화면 위 글자 수 |
|---|---|---|
| 1일차 첫 작전 | 39% | 95자 |
| 9일차 (일병, 바쁠 때) | 67% | 189자 |

- 첫 출동 전에 교범 4장 + 프롤로그 9줄, 작전 중에도 이야기 장면이 끼어든다
- 1일차부터 간부 순찰·빙판·콤보·특명·처마 눈·고라니·돌발 상황이 다 나온다
- HUD 버튼 5개, 지시서 카드 4~6줄, 버프 줄, 말풍선·알림이 동시에

## 2. 단계별 공개 (`SNOW.FEATURES`)

처음엔 **걷기 → 퍼 담기 → 집하장 → 보고**만. 구역이 늘거나 진급할 때마다 하나씩 열린다.

| 언제 | 새로 생기는 것 |
|---|---|
| 처음 | 걷기·퍼 담기·집하장·보고, 버튼은 정지 하나 |
| 첫 작전 끝 | 생활관 보급(장비 상점)·꾸미기 |
| 족구장 (★3) | 간부 순찰 + 경례, 콤보·폭풍 제설, 분대원(전입 요청)·전화, 보급 상자·훈장, 남은 눈 보기(돋보기) |
| 일병 | 빙판·염화칼슘, 오늘의 특명, 처마 눈, PX, 뽑기, 포상휴가, 특기 |
| 연병장 (★8) | 고라니, 시점 버튼, 가공 공장 |
| 상병 | 돌발 상황 (폭설 경보·공병대 지원·사단장님 불시 방문) |

- 새로 열린 건 다음 작전 **브리핑에 "새로 생김" 한 칸**(최대 3개, 한 줄씩)으로만 알린다
- 생활관 버튼·상점 탭도 열릴 때 나타나고, 처음 보면 초록 **N** 표시 (누르면 사라짐)
- 예전 저장(v10~v12)은 이미 열린 기능을 "봤다"로 처리 — 갑자기 N이 쏟아지지 않는다
- 전역 후 이병부터 다시 하면 생활관 보급·꾸미기는 바로 열려 있고, 나머지는 구역·계급을 따라 다시 열린다 (이미 소개한 건 "새로 생김"에 또 나오지 않는다)

## 3. 덜 읽기

| 전 | 후 |
|---|---|
| 첫 출동 전 교범 4장 | 없음 (생활관 '교범' 버튼으로) — 위 한 줄 '지금 할 일'과 노란 화살표로 충분 |
| 프롤로그 9줄 | 5줄 (이름은 2번째 줄에서) |
| 작전 중 이야기 장면 | 생활관에 돌아왔을 때만 (프롤로그 빼고) |
| 행보관 말풍선 상시 | 중요한 것만 (심사·폭설·고라니·차·처마·졸음·불시 방문 등) |
| 조작 안내 2줄 | 한 줄 "끌어서 걷기 · 노란 화살표를 따라가" |
| 지시서 카드: 구역 1곳이어도 4~6줄 | 구역 2곳 이상일 때만, 2줄 (작은 폰은 3칸씩) |
| 버프 줄 | 숨김 |
| 3D 위 '가득!' 글씨, 모든 분실물 알림 | '가득!'은 위 한 줄이 알려 줌, 분실물은 희귀 이상만 |
| 브리핑 특이사항 5~7줄 | 심사·날씨·검열·출근 차량만 |
| 로비 소식 4줄 | 2줄 (전역·심사 > 할 일 > 받을 것 > 특명) |
| 할 일(튜토리얼 퀘스트) 문장 | 짧게 ("끌어서 걷기", "노란 원에 붓기") |
| 결과 화면 8~10줄 | 4줄 (지시서·특명·문제 순) + "자세히" 눌러 펼치기 |

## 4. 폰 화면 더블체크

`tests/snow-ui-audit.js` (넘침·잘림·HUD 겹침, 4가지 크기 × 27장면) + `tests/snow-clutter.js` (덮인 비율·글자 수·내 캐릭터를 가리는 UI) + 화면 사진을 직접 확인.

| 크기 | 덮인 비율 (작전 화면) | 글자 수 |
|---|---|---|
| 360×640 | 22 ~ 30% (전 39 ~ 67%) | 44 ~ 88자 (전 95 ~ 189자) |
| 390×844 | 17 ~ 26% | — |

찾아서 고친 것:
- **경례 큰 버튼이 내 캐릭터를 가림** (390×844): 버튼을 아래로 내리고(작은 폰은 110px), 경례하는 동안 위쪽 작은 경례 알림은 숨김
- 초코파이 "30.0만"이 두 줄로 꺾임 → 한 줄 고정
- 콤보 설명이 비었을 때 빈 칸이 남음 → 숨김
- 412×915에서 구역 막대가 막 나타난 순간 콤보 숫자가 버튼 줄에 겹침 → 알림 줄 위치를 0.15초마다 다시 맞춤 (전 0.4초)
- 이야기 장면이 열린 채 생활관으로 가면 장면 상자가 로비를 덮음 → 생활관으로 갈 때 닫는다
- 결과 화면이 작은 폰에서 확인 버튼 근처까지 꽉 참 → 4줄 + 자세히

남은 것 (의도):
- 새 구역이 열린 작전은 시작 후 약 3초 카메라가 그 구역을 비춘다. 그동안 내 캐릭터가 화면 가장자리로 갈 수 있다
- 브리핑은 상병·심사·분대원 배치까지 겹치면 여전히 길다 (작업 분담은 스크롤). 맨 위 행보관 한 줄과 아래 큰 버튼만 봐도 출동은 된다
